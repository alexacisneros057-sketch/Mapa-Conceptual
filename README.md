# Actividad 4 — Circuitería alternativa de E/S

Proyecto de **Sistemas Programables** desarrollado en **Python**.

## ¿Qué hace?

Genera un **mapa conceptual vectorial (SVG)** que sigue reglas de un mapa conceptual: tema principal, jerarquía, conceptos breves, palabras de enlace, flechas de relación, ejemplos y un enlace cruzado.

El contenido está dividido en:

* **Generalidades:** puertos GPIO, registros de control y circuitos de interfaz.
* **Dispositivos de visualización:** LED, LCD, OLED y TFT.
* **Codificadores de posición:** encoders incrementales y absolutos, con aplicaciones.

## Referencia de contenido

Temario de Sistemas Programables, unidad III, apartado 3.2 «Circuitería alternativa para entrada/salida» (3.2.1 Generalidades, 3.2.2 Displays, 3.2.3 Codificadores de posición), Tecnológico Nacional de México.
